REST API & Middlewares

A small Express server demonstrating GET/POST/PUT/DELETE and custom middleware, wired to a live Projects page.

This build includes:

  • A request logger middleware
  • A response timer middleware (adds timing to server logs)
  • A body-validation middleware for POST/PUT requests
  • Full CRUD on /api/projects, with an editable UI on the Projects page

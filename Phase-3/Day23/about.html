About AgriSense

A closer look at what AgriSense is, how it's built, and where it's headed.

AgriSense is a full-stack crop advisory platform built as part of the Innolift Ventures Full Stack AI Developer Program. It pairs a machine learning model trained on soil and climate data with a simple web interface so farmers can get a crop recommendation in seconds.

The idea is simple: instead of relying on guesswork, a farmer enters soil nutrients (N, P, K), temperature, humidity, pH, and rainfall, and gets back the crop best suited to those conditions.

Built With

Project Status

AgriSense is being built in phases through the internship. Here's where it stands.

Crop Recommendation Model

Frontend Interface

Landing, recommendation, about, and contact pages — the stage you're looking at right now.

Backend & Database

A Flask REST API backed by MySQL to store farm profiles and recommendation history.

Full Integration

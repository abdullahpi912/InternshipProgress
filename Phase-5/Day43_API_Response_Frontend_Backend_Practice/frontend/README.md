# Day 42 Frontend

## Run

```bash
npm install
npm run dev
```

Open http://localhost:5173

Make sure the Flask backend is running at http://127.0.0.1:5000.

If the page was blank before, delete `node_modules` and `package-lock.json`, then run `npm install` again so the React/Vite versions in `package.json` are installed cleanly.
